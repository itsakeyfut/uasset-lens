# `completions` Command — Options

## Synopsis

```
uasset-lens completions <shell>
```

---

## Arguments

| Argument | Required | Description |
|---|---|---|
| `<shell>` | Yes | Shell to generate completions for: `bash`, `zsh`, `fish`, `powershell`, `elvish` |

---

## Options

This command has no options. Global flags (`--format`, `--db`, `--config`, `--yes`)
are accepted by the parser but have no effect.
